# Contributing to poweradmin-go

## About this project

poweradmin-go is an open source Go SDK maintained by Patrick Omland
(Contentways) as an independent community project. It is not affiliated with
the Poweradmin project itself, though collaboration with the Poweradmin
maintainers is actively encouraged.

**Development happens publicly on GitHub.** All design decisions, issues, and
pull requests are discussed openly here. There is no separate internal
development track.

The goal is to provide a well-tested, idiomatic Go client for the Poweradmin
API — useful for anyone building automation, operators, or tooling around
Poweradmin. Contributions, feedback, and questions are genuinely welcome.

If you are unsure whether your idea fits the project, open an issue and let's
talk about it before you invest time in a PR.

Thank you for considering contributing to **poweradmin-go** — a Go SDK for the [Poweradmin](https://www.poweradmin.org/) DNS management API.

## Getting Started

### Prerequisites

- Go 1.24+
- [pre-commit](https://pre-commit.com/) (`pip install pre-commit` or `dnf install pre-commit`)
- [golangci-lint](https://golangci-lint.run/) v2.12+

### Setup

```bash
git clone https://github.com/contentways/poweradmin-go.git
cd poweradmin-go
go mod tidy
cd tools && go mod tidy && cd ..
pre-commit install
```

## Project Structure

```
poweradmin-go/
├── poweradmin/         # SDK package (domain types, resource clients)
│   ├── schema/         # Raw JSON types — 1:1 API mapping, never use directly
│   ├── zz_*.go         # Generated files — do not edit manually
│   ├── schema_conv.go  # hand-written schema ↔ domain conversions
│   └── generate.sh     # Runs all code generators
└── tools/
    └── go.mod          # Isolated module for code generation tools
```

## Code Generation

Several files are generated automatically and must not be edited by hand — they are prefixed with `zz_`:

| File | Generated by | Source |
|---|---|---|
| `zz_*_client_iface.go` | ifacemaker | `*.go` resource client structs |
| `zz_schema_converter.go` | goverter | `schema_gen.go` |
| `zz_schema.go` | gowrap | `schema_gen.go` + `schema.tmpl` |

After changing any resource client or schema type, regenerate:

```bash
cd poweradmin
go generate ./...
```

The `pre-commit` hook runs `go generate` automatically before every commit.

## Making Changes

### Adding a new resource

1. Create `poweradmin/<resource>.go` with the domain type, `*Opts` structs, and the `<Resource>Client` struct with its methods.
2. Add the new client field to the `Client` struct in `client.go` and wire it up in `NewClient()`.
3. Add the corresponding schema types to `schema/schema.go`.
4. Add the conversion methods to the `converter` interface in `schema_gen.go`.
5. Add a new `ifacemaker` line to `generate.sh`.
6. Run `go generate ./...`.

### Commit Messages

We use [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add PermissionTemplate resource client
fix: correct pagination handling in ZoneClient.All
chore: regenerate zz_* files
docs: update CONTRIBUTING.md
```

Allowed types: `feat`, `fix`, `chore`, `docs`, `test`, `refactor`.

### Pull / Merge Requests

- One logical change per MR — keep them small and focused.
- All `pre-commit` hooks must pass before opening an MR.
- Add or update tests for any non-trivial logic.
- Generated `zz_*` files must be up to date — run `go generate ./...` before committing.

## Running the Linter

```bash
golangci-lint run ./...
```

The linter config is in `.golangci.yaml`. Please do not disable linter rules without discussion.
